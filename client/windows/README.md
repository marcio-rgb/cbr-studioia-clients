# Omni Remote Client (Windows)

Este pacote contém o cliente de navegação remota com suporte aos motores antidetect **Camoufox (Firefox C++ Stealth)** e **Playwright (Chromium Stealth)**.

## 🚀 Como Executar

1. Extraia o arquivo `omni-playwright-client-windows.zip`.
2. Escolha o motor de navegação desejado e dê 2 cliques:
   - 🦊 **`start_camoufox.bat`**: Motor Antidetect Camoufox (Firefox C++ Stealth - Recomendado)
   - 🌐 **`start_playwright.bat`**: Motor Playwright Chromium Stealth
   - ⚡ **`start.bat`**: Inicializador padrão (Camoufox)

---

### ⚙️ Conectar a outra URL de VPS
Para conectar a um servidor diferente do padrão (`ws://ia.creditobr.com.br:8384`), abra o Prompt de Comando (cmd) na pasta e execute:

```cmd
start_camoufox.bat ws://SEU_IP_OU_DOMINIO:8384
```
